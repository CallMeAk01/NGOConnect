🚀 Key Features

🗺️

Live Rescue Map

Color-coded case markers across India. Red = Critical, Yellow = Moderate, Green = Stable. Click for instant case details.

📍

Nearest NGO Auto-Dispatch

Haversine distance algorithm finds the closest verified NGO within 50km radius. Critical cases auto-assigned in seconds.

🛡️

NGO Credibility Scoring

Weighted algorithm — Response Speed (30%), Success Rate (30%), Transparency (20%), Community Rating (20%).

⚡

Fail-Safe Auto-Escalation

If a critical case isn't resolved in 30 minutes, the system automatically escalates to the next nearest NGO.

💳

Secure Payment Gateway

📊

Impact Analytics Dashboard

Real-time rescue heatmap, city-wise leaderboard, response time analytics, and financial transparency dashboard.

📍 Nearest NGO Algorithm

Uses Haversine formula to calculate earth-surface distance between the animal's GPS coordinates and all verified NGOs within a configurable radius.

distance = 2R × arcsin(√(sin²(Δlat/2) +
  cos(lat₁)·cos(lat₂)·sin²(Δlng/2)))

⚡ Auto-Escalation Timer

If a critical case isn't claimed within 30 minutes, the system automatically reassigns it to the next nearest NGO, ensuring no animal is left waiting.

How It Works

Each NGO gets a credibility score from 0–100, displayed as a badge on their profile. Higher scores mean priority dispatch for new cases. Low-scoring NGOs get improvement recommendations, not punishment — ensuring the system improves animal welfare outcomes across the board.
