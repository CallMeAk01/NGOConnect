📌 Project Overview

NGO Connect is a full-stack web application built to bridge the gap between people who spot distressed animals and verified NGOs who can rescue them. The platform emphasizes complete financial transparency, real-time tracking, and data-driven NGO accountability.

🔐 Authentication Flow

Email / Password

User fills form → POST /api/auth/login → bcrypt compares password
→ JWT issued → stored in localStorage → redirect to dashboard

Google OAuth

Click "Continue with Google" → GET /api/auth/google
→ Passport redirects to Google consent screen
→ User approves → Google redirects to /api/auth/google/callback
→ Backend issues JWT → redirects to /#/auth/callback?token=...&user=...
→ Frontend stores token → redirect to role-based dashboard

Auth Strategies (Passport.js)

  • LocalStrategy — email + bcrypt password validation
  • JwtStrategy — Bearer token from Authorization header
  • GoogleStrategy — Google OAuth2 via passport-google-oauth20
  • Password hashing: bcrypt with salt rounds = 12
  • JWT expiry: 7 days

🧠 Smart Features

1. Geospatial NGO Matching (Haversine Formula)

When a case is created, the backend calculates the distance between the case GPS coordinates and every verified NGO using the Haversine formula. It finds all NGOs within a 50km radius, sorts them by distance, and if the urgency is CRITICAL, automatically assigns the nearest NGO.

2. Auto-Escalation System

A setInterval runs every 5 minutes in main.ts. It checks for cases that have been stuck too long without resolution and automatically reassigns them to the next nearest available NGO, then emits a case:escalated WebSocket event.

3. Credibility Score Algorithm

A composite score (0–100) for each NGO calculated from 4 weighted factors:

FactorWeightHow Calculated
Response Speed35%Avg minutes from case assignment to first activity log. ≤30min = 95pts
Success Rate30%Resolved cases ÷ Total assigned cases × 100
Transparency20%Cases with financial records ÷ Total cases × 100
Community Rating15%Star rating (0–5) scaled to 0–100

Grade: Excellent (≥80) / Good (≥60) / Developing (<60)
